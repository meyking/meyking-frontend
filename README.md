## Working on this with an AI assistant

`AGENTS.md` has the setup steps and the rules for this repo. Claude Code reads
it through `CLAUDE.md`, and Codex (the coding agent in ChatGPT) reads it
directly.

1. Clone the repo: `git clone git@github.com:meyking/meyking-frontend.git`
2. Open the folder in a coding session:
   - Claude desktop app: the Code tab, then choose this folder.
   - ChatGPT desktop app: Codex, then choose this folder.
3. Ask it: "Set me up to work on this site, following the first-time setup in
   AGENTS.md."

A normal chat window in either app cannot see the files or run commands, so the
instructions only apply in a coding session opened on this folder.
